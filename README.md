# Portugal Mutual Savings Cooperative

A modern, responsive static website for **Portugal Mutual Savings Cooperative**, a community-based cooperative based in Évora, Portugal.

The cooperative is established to promote savings, financial cooperation, mutual support, and community development among its members.

## 🌐 Website

This project is designed as a lightweight static website that can be hosted using:

- GitHub Pages
- Netlify
- Vercel
- Any standard web hosting service

## 🎯 Purpose

The website provides information about:

- The cooperative
- Membership
- Savings and financial cooperation
- Member benefits
- Cooperative activities
- Rules and policies
- News and announcements
- Contact information

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Clean and professional financial/cooperative design
- Simple navigation
- About Us section
- Membership information
- Savings information
- Member benefits
- Frequently Asked Questions (FAQ)
- Contact section
- Mobile-friendly layout
- SEO-friendly structure
- Fast-loading static pages

## 🛠️ Technologies

The website is built using standard web technologies:

- HTML5
- CSS3
- JavaScript
- Bootstrap (if applicable)

No backend or database is required for the initial version.

👥 Membership

The cooperative is intended for its registered members. Membership information, eligibility requirements, contributions, savings arrangements, and other conditions will be published according to the cooperative's approved rules and applicable Portuguese requirements.

🔐 Privacy & Security

The website should not collect or publish sensitive financial or personal information through static pages.

Any future member-management or financial system should use appropriate authentication, data protection, and security measures.

⚠️ Important Notice

This website is an informational website for the cooperative.

Information regarding savings, contributions, loans, returns, membership, and other financial activities must be implemented and published only in accordance with the cooperative's approved rules and applicable laws and regulations in Portugal.

The website does not constitute a bank or financial institution unless the organisation has obtained the necessary legal status and authorisations.
